# 해부생리 기말고사 대비 퀴즈

특수감각계통(3), 신경생리, 중추신경계통(1) 교안을 바탕으로 구성한 5지선다 퀴즈입니다. 단원별 80문항씩 총 240문항이며, 정답을 확인하면 해설과 해당 교안의 PDF 페이지를 볼 수 있습니다.

## 실행 방법

파일을 내려받은 뒤 `index.html`을 브라우저에서 엽니다. 단원, 난이도, 문항 수를 골라 연습할 수 있습니다. 오답 기록은 사용 중인 브라우저에 저장됩니다.

## 의학용어 암기

세 교안에서 40개씩 고른 의학용어 120개를 한곳에 모았습니다. 영어에서 한글로, 한글에서 영어로, 또는 두 방향을 섞어 연습할 수 있습니다. 각 방향에 120개 문항이 있으며, 정답을 확인하면 용어의 짝과 출처 페이지가 나옵니다.

의학용어 문항 옆의 표시는 교안의 영어 글자색을 따릅니다. 빨강은 **최우선**, 분홍·파랑·청록·보라는 **중요**입니다. 같은 용어가 여러 색으로 나오면 가장 높은 등급을 표시합니다.

기말고사 문항과 해설은 `questions.js`, 의학용어와 출처는 `terms.js`에 있습니다.
